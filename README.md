# movie-magic-expressJS
Back End Course Workshop by SoftUni

Movie Magic Express is a full-stack web application built with Node.js, Express, MongoDB, and Handlebars.
It allows users to register or login, add movies and browse movies.


Tech Stack:
Node.js
Express.js
MongoDB (Mongoose)
Express-Handlebars (HBS)
Express Session & Cookies
MVC Architecture

Features:
User registration & login (session-based authentication)
Create, view, and manage movies
Attach cast members to movies
Dynamic star rating display
Flash messaging system
Server-side rendering with Handlebars

🏗 Architecture
This project follows a 3-Layer Architecture pattern, which separates the application into distinct logical layers for better scalability, maintainability, and clean code organization.
1. Presentation Layer (Controllers + Views)
2. Business Logic Layer (Services)
3. Data Access Layer (Models)

How to Start:
1. Clone the repository

2.  Install dependencies
npm install

4. Start MongoDB
Make sure MongoDB is running locally.

5. Run the application
npm start

6. Open in browser
http://localhost:5000
